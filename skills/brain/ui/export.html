🧠 Export a project's brain

Pull every entry for one scope into a single Markdown file. Copy it to another PC and any Freebuff agent can read the full scope instead of piecing it back together entry by entry.

1. Pick the scope to export

2. Choose what to include

Entry types

Ctrl/Cmd-click to deselect. Default: all types.

3. Preview / generate

4. The exported Markdown

One file - paste it into an agent prompt, drop it in a Markdown tool, or save it as scope-NAME.md and ship it alongside the project.

5. How an agent consumes it on another PC

Paste the whole block into a Freebuff agent prompt along with:

  • The project folder path on that machine (if relevant).
  • Any question you want it to answer from that scope's history - "what ports did this project use", "what bugs were fixed", "what's the current state", etc.

The Markdown is self-contained: each entry keeps its title, type, scope, tags, created/updated dates, source, and body, so the agent doesn't need a live brain to understand the project's context.
